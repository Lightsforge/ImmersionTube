# ImmersionTube

ImmersionTube is a desktop application designed for language learners who want to track their immersion time and stay consistent with their studies.

## Features

- ⏱ Track total immersion hours
- ▶️ Watch videos directly inside the app
- 🔗 Import content from YouTube links
- 📊 Monitor long-term learning progress
- 🎯 Stay motivated with measurable goals

## Why Immersion?

Language acquisition improves through consistent exposure to authentic content. ImmersionTube helps you focus on what matters most: spending time with your target language.
